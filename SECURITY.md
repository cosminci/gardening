# Security Policy

## Intended deployment

This app has no application-level authentication. It is built to run on a home NAS, reachable only over LAN and Tailscale — never exposed to the public internet. Running it on an open network is a misconfiguration, not a supported use case.

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/cosminci/gardening/security/advisories/new) rather than a public issue. Include steps to reproduce and the affected version/commit.

## Supported versions

This is a single-deployment personal project with no version branches; fixes land on `main` and are deployed on the next release.
